## Introduction

This repository contains my personal solutions for the problem sets from Harvard University's CS50x: Introduction to Computer Science. This course is an incredible journey through the fundamentals of computer science and programming, from C to Python, SQL, and web development.

### ⚠️ A Note on Academic Honesty

These solutions are intended for **reference and educational purposes only**. If you are currently enrolled in CS50, I strongly encourage you to attempt every problem set on your own first. The real learning comes from grappling with the problems and finding your own solutions.

> **Please do not copy and paste this code** as your own submission. Use it as a guide *only* if you are truly stuck. Always adhere to CS50's academic honesty policy.

## Weekly Breakdown

Here is a brief overview of the topics and problem sets covered each week.

### Week 0: Scratch 👾
* **Topic:** Introduction to programming fundamentals using the Scratch visual programming language. Covers concepts like functions, loops, conditions, and variables.
* **Problem Set:** An open-ended project of your own design in Scratch.

### Week 1: C 🚀
* **Topic:** A deep dive into the C programming language. Covers the command line, data types, operators, and conditional logic.
* **Problem Sets:** `hello`, `mario` (less and more), `cash`, and `credit`.

### Week 2: Arrays 🔡
* **Topic:** Working with arrays, strings, command-line arguments, and basic cryptography.
* **Problem Sets:** `readability`, `caesar`, and `substitution`.

### Week 3: Algorithms 🗳️
* **Topic:** Algorithm efficiency (Big O notation), recursion, and different sorting and searching algorithms (e.g., bubble sort, merge sort).
* **Problem Sets:** `plurality`, `runoff`, and `tideman`.

### Week 4: Memory 🧠
* **Topic:** Understanding memory in C, including pointers, memory allocation (`malloc`, `free`), file I/O, and data structures.
* **Problem Sets:** `filter` (less and more) and `recover`.

### Week 5: Data Structures 📖
* **Topic:** Implementing and using more complex data structures like linked lists, hash tables, and tries to optimize performance.
* **Problem Set:** `speller` (a comprehensive spell-checker).

### Week 6: Python 🐍
* **Topic:** Transitioning from C to Python. Covers Python's syntax, data structures (lists, dictionaries, tuples), and common libraries.
* **Problem Sets:** Re-implementing `hello`, `mario`, `cash`, and `readability` in Python, plus `dna`.

### Week 7: SQL 📊
* **Topic:** Introduction to databases using Structured Query Language (SQL). Covers `SELECT`, `INSERT`, `UPDATE`, `DELETE`, and `JOIN` operations.
* **Problem Sets:** `movies` and `fiftyville` (a SQL mystery).

### Week 8: HTML, CSS, JavaScript 🌐
* **Topic:** Front-end web development. Building static web pages with HTML (structure), CSS (style), and JavaScript (interactivity).
* **Problem Sets:** `homepage` (creating your own personal website).

### Week 9: Flask 📈
* **Topic:** Back-end web development using Python and the Flask framework. Covers web applications, sessions, and integrating databases.
* **Problem Set:** `finance` (a virtual stock trading website).
